# @deepseek-ai/dsh-client-ui-boot-animation

[English](README.md) | 中文

## 概述

`@deepseek-ai/dsh-client-ui-boot-animation` 在客户端启动时、或进入新会话时，于整个窗口上播放两段式启动体验：先播六幕档案序列，再播一段片头视频。设置里的「启动片头」页面负责两段顺序、序列的每一项偏好、片源库与播放时机。包内自带 4 段片源与 6 段录音台词；放进用户视频目录的 MP4、M4V、MOV、WebM 文件会加入片源库。每个会话可以设为反复播放，也可以单独指定片源；点「跳过」或按 Esc 会结束整段体验。Web 与 Desktop 默认开启。

## 使用本包

发布的 Web 组合以 `ui-boot-animation` 挂载片头，因此 Web GUI 与 Desktop 默认都会播放；用户能调整的内容都在设置的「启动片头」页面，页面文案跟随当前界面语言。

### 档案序列

第一段是六幕的「访问授权」序列：黑幕上的鲸鱼标识与 DeepSeek 字标 → 过曝洗白 → 暖白档案底板 → 五步授权 → 欢迎幕 → 色散揭幕后交给片头视频。文字后面有一圈缓慢自转的准星，角标计数器从 `[ 01 / 06 ]` 一路走到终幕，进度条随之填满。整套序列随主题切换暖白或暗色，也可以把底板换成覆盖在应用之上的半透明磨砂玻璃。

五句台词各自是「中文主字 + 英文等宽副标题逐字打出」，底部另有一行日志。其中两句会停下来等你：第一句要求授予访问权限，第二句要求确认按钮旁弹出的身份卡，点按钮、按 Enter 或空格都能继续；另外三句自动推进。每一句都会念出来：包内自带 6 段录音，序列会等这句念完再走下一句，所以点得快也不会把语音掐断。素材缺失或把 `screenVoiceSource` 设为 `'tts'` 时，改用系统合成音念同一句。界面音效（提示「哒」声、双音确认、落幕钟声）伴随各幕，仅在 `screenSound` 开启时播放。

`screenSpeed` 会缩放所有固定时长，但每一句仍要等念完才推进；`screenRequireInteraction` 关掉两处确认门；`screenAllowSkip` 控制跳过控件与 Esc——跳过会结束整段体验，而不是接着播视频。品牌三行、黑幕三行、终幕方框、页脚、身份资料与三种配色都是设置项，不是常量。

### 片头视频

片头铺满窗口，画面上只保留「跳过」按钮和一行状态提示。由于浏览器禁止有声自动播放，片头一开始是静音的；点击画面会打开声音并请求全屏，而全屏请求只有在这次点击之内才会被浏览器接受。「跳过」和 Esc 立即关闭片头；片源播放结束或解码失败时同样关闭，失败时用一段提示替代画面。这行状态提示反映首帧是否到达：元素还在加载时显示「正在加载视频…」，首帧绘出后换成「点击开启声音 · 全屏」。若 25 秒内没有出现可播放帧，先显示「加载超时」再关闭，而这段时间内迟到的首帧仍会正常播放。

浮层位于客户端其余界面之上、对话框之下，所以播放期间弹出的审批或对话框仍然可见可用。设置页的「预览」通过同一浮层播放，并带有预览标记，不会改变已选片源。

### 什么时候播放

`timing` 决定自动播放的时机。`app-start` 每次启动播放一次；`entry` 在进入一个还没有任何轮次的会话时播放，每个会话在本次启动内只播一次。两种方式的记录范围都是一次启动：刷新页面会重新播放，新开的标签页有自己的记录，而回到某个会话时不会重播，除非该会话自己的设置要求每次进入都播。关闭 `enabled` 后不再自动播放，预览仍然可用。

启动记录和按会话记录保存在 sessionStorage 中；浏览器拒绝存储时改用内存记录。

### 片源

包内 `assets/` 自带 4 段片源，列在片源库最前面，无需任何配置。把自己的视频复制到 `$DSH_HOME/boot-animation/videos/`（插件在启动时创建该目录），再到设置页点「刷新」，它就会加入片源库。支持的格式为 MP4、M4V、MOV 和 WebM；空文件和隐藏文件会被跳过。

片源身份有两种：包内自带的为 `builtin:<key>`，用户文件为 `file:<stem>-<hash>`，其中 hash 覆盖文件的绝对路径。因此重命名或移动文件会得到一个新 id，原先的选择找不到对应片源时回落到列表中的第一段，而不会用旧名字播放另一段内容。覆盖文件内容不会改变 id，但会改变版本，浏览器随后会取到新的字节。

### 偏好设置

| 字段 | 默认值 | 含义 |
|---|---|---|
| `enabled` | `true` | 是否自动播放片头 |
| `timing` | `'app-start'` | `app-start` 每次启动播放一次；`entry` 进入空会话时播放 |
| `fit` | `'cover'` | `cover` 铺满窗口并裁掉边缘；`contain` 完整显示画面 |
| `random` | `false` | 每次随机播放一段，而不是播放 `selectedClip` |
| `selectedClip` | `'builtin:brand'` | 关闭随机播放时播放的片源 id |
| `sequence` | `'archive-then-video'` | 播哪几段、什么顺序：`archive-then-video`、`video-then-archive`、`archive-only`、`video-only` |

这些是可变的 Config 字段：设置页直接写入正在运行的入口，改完立即生效，不需要编辑配置文件。完整的字段说明见生成的[配置目录](../../../docs/config-catalog.zh.md#deepseek-aidsh-client-ui-boot-animation)。

### 按会话覆盖

设置页的第三组只作用于当前打开的会话。「每次进入都播」让片头在你每次进入该会话时播放，优先于两种播放时机；片源下拉为该会话单独指定一段片源，默认跟随全局选择。宿主按会话保存这两个字段，所以重启后、以及指向同一宿主的其他浏览器中同样有效。宿主没有持久化存储时，该组会说明自己不可用，页面其余部分照常工作。

<a id="understand-the-implementation"></a>
## 理解实现

浏览器页面无法读取文件系统，也无法跨浏览器记住选择，因此片源发现、片源字节、「现在该播哪一段」以及按会话覆盖的持久化都由宿主负责；浏览器负责什么时候播放，以及用户看到什么。

<details>
<summary>实现内部细节 — 点击展开</summary>

所有路由都在 `/dsh-boot-animation` 下，且只对所有者开放：注册时要求身份认证，处理函数对非所有者身份返回 403，片源 id 只用于在已发现的片源库中查找，从不作为路径使用。`catalog.json` 返回片源列表、询问方会话的覆盖设置，以及覆盖功能是否可用；`active.json` 回答唯一的「现在该播哪一段」；`POST session` 合并一个会话的覆盖设置。`media/<clipId>` 输出字节：Content-Type 按扩展名决定，支持单区间 `Range` 并返回 206，提供 ETag 供 `If-None-Match` 复验，并且只有 `?v=` 与该片源当前版本一致时才返回 `public, max-age=31536000, immutable`，否则返回 `no-cache`。所有失败（包括 403、404、416 和 500）都返回 `no-store`，避免一次瞬时错误长期留在浏览器里。

片源扫描结果按每个条目的 size 与修改时间组成签名缓存。只用目录级签名无法察觉文件被就地覆盖，那会继续发布旧版本，让 `?v=` 把过期字节长期缓存下去。同一组 size 与修改时间就是片源的版本，也因此长的缓存有效期是安全的。

唯一的解析器负责整条优先级链：会话覆盖、随机播放、`selectedClip`，最后是列表中的第一段。随机播放会在宿主进程内记住上一段，并在还有其他片源时排除它，所以连续两次片头不会相同；这份记忆只在真正请求随机结果时推进，刷新片源库或读取状态不会消耗它。

档案序列由一个 `Frame` 对象描述「此刻屏幕上的一切」并由一条时间线函数驱动；跳过时用一个哨兵拒绝所有待等待的计时，于是收尾只有一条路径，而不是每一步各写一个分支。它的声音引擎藏在一个可注入的工厂之后，同一套引擎在浏览器里驱动真实的媒体元素、在测试里驱动普通假对象，一次 `stop()` 就能停掉所有元素并取消合成器。跨帧存在的东西——身份资料、文案、配色、玻璃——都来自设置投影，而不是从宿主线缆传下来。

只要有一段正在占用窗口，浏览器面就会在文档元素上设置 `data-dsh-splash`。Desktop 外壳读取该属性，把 Windows 标题栏按钮连同其底色一起隐藏，并在属性移除时恢复；浏览器会忽略它。

序列的艺术样式表 `src/client/archive/archive.css` 是一份普通的全局样式表，作用域收在 `.dsh-boot-archive-root` 下，自定义属性使用 `--dba-*` 前缀。它承载约一百个元素与 11 个关键帧；改用 CSS Modules 只会多一张名字表，并不会带来复用，而类名前缀保证这份样式表碰不到应用的其他部分。

覆盖设置存放在 `@deepseek-ai/dsh-storage-domain` 的 `boot_animation` 域、`sessions` 表中，每个会话一条 `{ replay, clipId }` 记录；两个字段都未设置的记录会被删除，而不是留成空记录。插件通过可选的 `storageDomain` 注入打开该域，所以没有存储的宿主照样播放片头，只是覆盖设置不可用。

浏览器面镜像宿主的设置投影，跟随当前会话绑定，并在每次相关变化时调用纯函数 `decidePlay`。该函数接收设置、会话标识、会话的空白标志和两条记录，返回「播放及其原因」或「不播放及其原因」。只有宿主确实返回了片源的播放才会写入记录，解析失败的播放留到下一次评估重试，不会白白消耗一次启动。两个注册负责呈现结果：`shell.overlay`（id 为 `boot-animation`）渲染播放器，`settings.section`（id 为 `boot-animation`，order 40）渲染「启动片头」页面。两者都通过注入的 `hooks` 隔间拿到裸可观察对象；组件只负责渲染和回调，不持有自己的生命周期。

文案集中在 `src/client/locales.ts` 的 `bootAnimation` 命名空间下，共 8 种语言；`locale/*.json` 只提供插件的展示元数据。

插件为本入口声明 `settings.configure({ auto: false })`，避免通用设置表单重复接管「启动片头」页面已经在编辑的字段。

<a id="model-experience"></a>
## 模型体验

无：本浏览器包不注册模型工具、提示词区段或会话事件；片源选择、播放和偏好都只停留在浏览器与宿主的呈现状态中。

#### KV Cache 影响

无。片头保存的内容——已选片源、播放时机、会话覆盖——都不会进入模型请求，因此不会影响任何已缓存的请求前缀。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- **没有系统文件选择器**：设置页无法打开操作系统的文件对话框，用户需要把视频复制到 `$DSH_HOME/boot-animation/videos/` 后点「刷新」；该目录之外的文件不会被列出。
- **`screenSfx` = `'synth'` 仍播放录音音效**：现场合成的音效尚未实现；设置项会保存并展示，但两个取值目前都播放包内的音效文件。
- **`screenVoiceLang` = `'both'` 实际念英语**：录音台词只有英语，合成路径每句只说一种语言，所以「两者」目前等同于 `'en'`。
- **背景模糊只作用于覆盖层内部**：`screenGlassBackdropBlur` 模糊的是覆盖层自身图层背后的内容；本包不会给应用节点加 `filter`，因此播放期间自行重绘的应用元素不会被模糊。
- **录音台词的权利**：6 段录音来自上游 startup-screen 插件，其音频取自第三方视频；本包按原样发布，相关权利由发布方负责。
- **内置片源的品牌与版权**：包内 4 段片源按原样发布，其品牌和授权由发布方负责，本包不做任何校验。
- **`timing` = `entry` 可能错过绑定较慢的情况**：该模式依赖会话的空白标志在绑定之后落定；绑定耗时很长时，这一次进入可能没有片头。
- **移动端全屏差异尚未覆盖**：全屏请求和视口单位按桌面浏览器行为处理，未单独适配移动端浏览器界面和移动端全屏 API。
