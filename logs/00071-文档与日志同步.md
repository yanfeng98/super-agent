## 1. 007 的面板边界段落已经过时

原文写“Other panel actions have equivalent tools”，这在把主会话收敛到 17 个工具之后已经不成立：批准、改名、标签、丢弃、单独 rebase 都没有工具。

改成明确列出面板独有的动作，并说明合并是主会话唯一执行的收尾动作、只在人明确要求时执行，需要时自动 rebase、跑 check、带 `cleanup` 清理。

## 2. 006 的管理 API 表缺两处

- 新增 `POST tickets/<id>/blockers`：`{ticket, blocked}`，返回 `blocked_by`（含 `id`、`number`、`title`、`merged`），并写明自依赖和成环会被拒绝。
- 合并那一行补上：被未合并的依赖工单挡住时拒绝；返回 `merged`、`branch`、`target`，需要时还有 `rebased` 或 `recaptured`。

`api.ts` 里合并响应的类型同步加上 `rebased?` 和 `recaptured?`，与面板实际收到的字段一致。

## 3. README 的快速开始

- 提到“向主会话要合并”时补上：主会话会先 rebase 前进过的主干、跑配置的 check；
- 工单可查看的内容里补上“合并前需先完成”的依赖工单。
