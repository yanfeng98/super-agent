# 00072 — 冲突交回、chat 依赖与可选 push

- **日期**：2026-11-19
- **背景**：对照 GitHub PR 流程整理出的三个剩余问题里，最难绕的是“合并时 rebase 冲突只能人再发一条消息”。这次把三条都补上：冲突自动交回 worker、主会话能在 chat 里记录依赖、合并可顺带 push。仍是本地合并，仍只在人明确要求时执行。
- **范围**：`src/app/review.ts`、`src/core/tickets.ts`、`src/core/engine.ts`、`src/app/runtime.ts`、`src/app/tools/main.ts`、`tests/merge.spec.ts`、`tests/chat-tools.spec.ts`、`tests/model-surface.spec.ts`、`docs/001`–`007`、`README.md`、`NATIVE.md`。

## 1. 冲突交回 worker

之前 `rebaseWorkspace` 冲突时只抛一句 `Rebasing onto X conflicts in a.txt; …`，`mergeTicket` 把它原样抛给调用方。用户在 chat 里说“合并”，主会话拿到这句报错后，还得自己再发一条消息把 worker 拉起来——这是整个流程里唯一必须人介入才能继续的地方。

- `src/app/review.ts` 新增 `RebaseConflictError`（`target` + `files`），消息文本保持不变，面板与既有测试的报错不变。
- `Runtime.rebaseTicket` 捕获它，调用 `Engine.resumeWithNote` 把冲突写成一条 `text` Input 并启动新 Assignment：说明目标分支、冲突文件、在该 worktree 里 `git rebase <target>`、`git add`、`git rebase --continue`，完成后重新 report ready。
- 交回成功时抛出的消息改成“…; the worker was told and is resolving it. Ask to merge again once it reports ready.”，主会话可以直接据此回人。
- 交回不成立时保留原来的纯报错：工单已被 stop（`ended.by === 'human'`）、已合并/丢弃/清理、Policy 暂停、或 Mandate 已不被当前 Policy 认账。这些都不该在没人要求时自动开工。
- `Tickets.resumeWithNote` 和 `wake` 的区别写进了 JSDoc：`wake` 要人的消息，`resumeWithNote` 是 host 在执行人的请求时发现的情况；`reopen` 则是人主动重开、文案固定。

## 2. 在 chat 里记录依赖

`blockedBy` 之前只能在面板里加，主会话听人说“等 T-0003 合完再合这个”无法记录。

- 新工具 `orchestrator_ticket_dependency`：`{ticket_id, blocker_id, blocked = true}`，调用 `Runtime.blockTicket`，返回 `blocked_by`（含 `id`、编号、标题、是否已合并）和工单卡片。自依赖和成环沿用已有的 `selfBlock` / `blockCycle` 拒绝。
- 工具描述里点名“面板显示和编辑同一个依赖”，避免模型以为这是另一套记录。
- 主会话工具数从 17 变 18（17 个应用工具 + `orchestrator_read`），模型可见文本预算从 60,300 提到 61,100；实际 61,045。

## 3. 合并时可选 push

- `mergeTicket` 增加 `options.push`。合并记录写完后、清理 worktree 之前调用新的 `pushWorkspace`（`git push`，用仓库自己的 upstream 和凭据，不新增设置）。
- push 失败不回滚合并：返回 `pushError`（`pushed` 为 true 时才是成功），主会话一次就能说清“已合并但没推上去”。
- 只在人同时说“合并并推”时传 `push: true`；面板的合并按钮行为不变。

## 4. 测试

- `tests/merge.spec.ts`：冲突时工单恢复为进行中、写入带 `git rebase main` 的 Input、清掉评审、不调用 `mergeWorkspace`；被 stop 的工单保留纯报错；`push` 成功返回 `pushed`，push 被拒时合并不撤销且返回 `pushError`。
- `tests/chat-tools.spec.ts`：新工具记录与清除依赖、自依赖被拒；合并工具的 `cleanup` / `push` 透传与默认值。
- `tests/model-surface.spec.ts`：预算上调到 61,100。
