# 00053 — 搜索限定词、批量操作、关联工单与操作历史

- **日期**：2026-11-18
- **背景**：对比 GitHub 清单第 5、6、7、12 项：搜索弱、无批量操作、无关联/交叉引用、工单页无操作历史。
- **范围**：`apps/web/native/dsh-superagent`（`src/app/views/threads.ts`、`src/app/views/tickets.ts`、`src/app/runtime.ts`、`src/app/http.ts`、`src/app/api.ts`、`src/core/*`、`src/client/*`、`docs/`、`tests/`）。

## 1. 改动

| 项 | 内容 |
|---|---|
| 搜索限定词 | `parseSearchQuery` 支持 `is:open`、`is:ended`、`tag:<name>`、`author:<id 或名字>`；未知 `is:` 值按普通文字处理 |
| 搜索范围 | 工单匹配新增请求正文（origin triggers 的 text），此前只匹配标题、回复、结果与标签；触发结果上限 20→30，工单 10→50，并用 `more` 标记截断 |
| 批量操作 | Execution 列表可多选：全选本页、取消选择；开放的工单批量停止，已结束的批量合并；逐个调用 API，失败计数提示，完成后清空选择 |
| 关联工单 | `Ticket.related` 与 `Tickets.link`（双向、幂等、拒绝自关联）；`POST tickets/:id/related` 接受 id 或 `T-000N`；工单页「关联工单」折叠区可添加/移除并跳转 |
| 操作历史 | 工单详情返回 `history`（批准、改名、合并、清理、丢弃，按时间排序）；页面新增「操作历史」区块 |

新增错误 `selfLink`（工单不能关联自己）及中英文案。

## 2. 验证

- `tests/views.spec.ts`：限定词组合、请求正文命中、关联工单编号/标题、无结果时行为。
- `tests/local.spec.ts`：双向关联、重复关联幂等、自关联与未知工单拒绝、解除关联。
- `tests/http.spec.ts`：`POST tickets/:id/related`。
- `tests/panel-execution.spec.tsx`：批量停止与批量合并各发一次 POST、关联/解除关联、操作历史渲染。
- 全量包测试 64 文件、1265 用例通过；`tsc --noEmit` 通过。

## 3. 仍按设计不做

- 标签颜色/描述、里程碑、优先级、截止日期：单人使用自由标签已够用。
- 邮件/摘要通知：Webhook 可接入任意通道。
- 镜像已有 GitHub Issue 列表：GitHub Source 在开启 `observeIssues` 时会把新 Issue 作为触发接收，不提供待办列表镜像。
