# 00057 — 同步上游 0.2.2-rc.4

- **日期**：2026-11-18
- **背景**：上游 `deepseek-harness` 在 rc.3 之后前进了 807 个提交（519 个非 merge），并打出 `dsh-v0.2.2-rc.4` 标签（2026-11-17）。本仓库上次的同步点是 rc.3 发布线（2026-11-13），`main` 在其上累积了 94 个本仓库提交。用户要求先核对上游更新，再决定是否先同步、后继续改造。
- **判断依据**：本仓库改动最密集的 `client/ui-chat`、`client/ui-conversation`、`client/ui-workspace` 与 `api/session-controller` 正是上游这一轮改动最猛的地方，越晚同步冲突越贵；试合并实测只有 32 个冲突文件，其中约 20 个是生成型文档。同步采用独立 `sync/rc4` 分支，验证通过后再合回 `main`。
- **范围**：整仓；重点在 `packages/session/session-persistence*`、`packages/api/session-controller`、`packages/client/ui-workspace`、`apps/web/native/dsh-*`、`docs/`、`logs/`。

## 1. 上游带来的变化

| 方向 | 内容 |

- `pnpm install`：8 个新 workspace 包接入，`tool-working-directory` 与 `mdast-util-from-markdown` 2.0.3 移除。

- `pnpm run build`：12/12（含原生 addon、IM bots、Superagent 与 Web 构建）。
- `pnpm run lint`：0 warning / 0 error（7532 个文件）。
- `pnpm run doc-sync`：43/43；`pnpm run test:docs`：21/21；`verify-translation-pairing`：1351 对全部一致。
- 单测：持久化与 session-controller 102 个文件 / 2310 用例；Client（`ui-workspace`、`ui-conversation`、`ui-chat`、`ui-settings-models`、`ui-commands`、`ui-primitives`）与 `llm-pi-ai` 273 个文件 / 5848 用例；Superagent 64 个文件 / 1271 用例。
- `pnpm run test:snapshot`：`pi-ai-conversation-updates` 通过；其余 18 个失败全部来自本机没有可用沙箱后端（bash 在 `workspace-write` 下被拒绝，错误文本明说「no sandbox backend is usable on this host」），与本次合并不相关。

## 5. 结果

- 本仓库与上游 `0.2.2-rc.4` 对齐，同时保留全部本仓库能力：11 个 pi-ai 路由 / 175 个模型、IM 原生渠道、Superagent 工单系统、永久删除会话、编辑重发、输入历史、启动片头。
- 唯一行为变化：把 profile 切到 SQLite 持久化时，永久删除会以 `session/delete-unsupported` 拒绝并提示改回 JSONL 后端；默认的 JSONL 后端行为不变。
