## 2. 关键决定

- **为什么用 hot-cold 而不是完整目录**：上游完整 `tools/list` 是 263 个工具、353 KB（约 122k tokens）；即使 DSH 用 `on-demand` 只列名称与首行描述，提示目录也有约 140 KB。`hot-cold` 初始只 advertise 5 个工具（7,876 B），其余经 `discover_tools` 按需加载；DSH 的 MCP client 已实现 `notifications/tools/list_changed` 重同步（`connection.ts` 的 `listChanged.tools.onChanged`），所以这条路径不需要改核心包。
- **为什么 `toolLoading` 默认 `on-demand`**：这个 server 的工具面太大，任何 `eager` 挂载都会把请求上下文压垮；默认值保护所有使用方，preset 再显式写一遍。
- **为什么源码放 `native/rea`**：与 `native/rust-anything` 同属“导入的上游源码子树 + 仓库构建产物”，`native/` 已被 lint/门禁按既有例外处理；它不是 DSH 插件（不参与 pnpm workspace 的 tsdown 构建），而是一个被 spawn 的外部 MCP server。
- **为什么用 `npm ci` 而不是把 43 个运行时依赖搬进 pnpm workspace**：上游只维护 `package-lock.json`，用 pnpm 解析会丢掉 lockfile 的确定性；隔离的 `npm ci` 保留上游的依赖图与 engine-strict 检查。
- **为什么 Node 26 只跑 `compile`**：上游 metadata/技能生成脚本通过 `module.stripTypeScriptTypes(..., {mode:"transform"})` 导入自己的 TypeScript 源；Node 26 移除了 transform 模式，脚本主动报错要求 `.nvmrc` 的 Node 24。`compile` 链（tsc + 三个 recorder + rolldown bundle）仍会生成 MCP 启动所需的 `dist/mcp/main.js`、目录摘要与 bundle；`skills/` 只影响 rea 自己的 `search_guidance`，而 DSH 的 `dsh-rea` 技能独立随包。

## 3. 行为

| 场景 | 结果 |
|---|---|
| 新 clone + `pnpm install && pnpm run build` | `rea MCP server` gate 在 `native/rea` 里 `npm ci`（首次约 3 分钟、约 880 MB，之后按 lockfile 摘要跳过）并构建（约 10 秒）；`standard` agent 拿到 `mcp-rea` 的按需目录与 `dsh-rea` 技能。 |
| 运行时 | server 以 Host 的 Node.js 启动；Node 24.22.3+ 满足上游 `^24.22.1` 与仓库 `^24.22.3` 的下限。 |
| 工具调用 | 初始 5 个工具 + `load_tools`；`discover_tools` 加载一页后 client 重同步；`load_tools` 把返回的工具加进当前 agent 的列表。 |
| 缺少构建产物 | `build:rea` 失败并给出可操作错误；运行时缺失时 MCP client fail-soft，不阻止 agent 创建。 |
| 打包运行时 | Desktop / Python SDK 可执行文件不会带上 `native/rea`，这两处不提供 rea 工具（与 rust-anything 相同的已知回退）。 |

## 5. 已知限制与后续

- CI 每个会构建/测试的 job 首次都要付 `npm ci` 成本（约 3 分钟）；后续可以给 `native/rea/node_modules` 加 actions/cache。
- Node 26 构建不生成 `skills/`，rea 的 `search_guidance` 工具在该运行时下返回 `bundle_unavailable`；MCP 调查工具不受影响。
- 深度原生分析依赖用户自装的 Hopper/Ghidra/IDA/JADX；Windows 原生 provider 的上游预编译产物不在仓库里，vendored 副本同样没有。
- 完整 263 工具目录很大；如果未来需要更窄的默认面，可在 preset 的 `env` 里用 `REA_MCP_TOOL_FAMILIES` 限定 family。
- 运行时观察/截图/环境录制会以 Host 用户权限执行被分析目标，属于工具本身的能力边界，技能与 README 已写明。
