# 00130 — 消除随包技能与 MCP 挂载的重复实现

- **日期**：2026-11-24
- **背景**：用户回复“继续修复”。上一轮 [00129](00129-修复集成遗留问题.md) 记录的 `pnpm run duplication` 仍有 9 处克隆（基线 5 处 + fast-anything 引入 4 处），CI 的 lint/duplication lane 因此为红。本轮把重复逻辑抽成共享实现，使其归零。
- **范围**：`packages/skill/skill/src/bundled-provider.ts`（新）、`packages/skill/{skill-engineering,skill-office,skill-rea,skill-rust-anything,skill-fast-anything}/src/index.ts`、`packages/skill/skill/package.json`、`packages/mcp/mcp-client/src/stdio-plugin.ts`（新）、`packages/mcp/{fast-anything,rust-anything,rea}/src/index.ts`、`packages/mcp/mcp-client/package.json`、`packages/api/settings-controller/src/{request.ts,authorization.ts,credentials.ts}`、`tsconfig.base.json`、生成的 config catalog、两个包的 README 双语与 pairing；`apps/web/native/dsh-superagent` 的既有测试类型/夹具。

## 1. 变更

| 位置 | 变更 |
|---|---|
| `packages/skill/skill/src/bundled-provider.ts`（新，子路径 `@deepseek-ai/dsh-skill/bundled-provider`） | 随包技能提供方的共享注册：严格/仅描述两种 frontmatter 解析器、assets 根解析、发现与加载生命周期、每技能一次的失败报告、候选投影与 `get()` 正文（含可选 `render`）。 |
| `skill-engineering`、`skill-office`、`skill-rea`、`skill-rust-anything`、`skill-fast-anything` | 改为声明身份常量与 `SOURCE`，`apply` 只调用共享注册；engineering 的多技能与 office 的 Python 环境正文追加保留在各自描述里。office 仍使用仅描述解析器并输出 `modelInvocable: true`。 |
| `packages/mcp/mcp-client/src/stdio-plugin.ts`（新，子路径 `@deepseek-ai/dsh-mcp-client/stdio-plugin`） | 共享的 stdio 挂载：`serverName`、命令、参数、`toolLoading`、单次调用/启动预算与额外环境；`STDIO_*` 默认值也在此。 |
| `fast-anything`、`rust-anything`、`rea` 插件 | `apply` 改调 `mountStdioServer`；rea 保留 launcher 解析与 `ELECTRON_RUN_AS_NODE` / catalog profile 环境。 |
| `packages/api/settings-controller/src/request.ts`（新） | 两个 Remote 命名空间共用的 `parseRequest`，消除同包内 10 行克隆。 |
| `packages/skill/skill/package.json`、`packages/mcp/mcp-client/package.json` | 新增子路径 `exports`；skill 包补 `lib/types/**/*.js` 到 `files`（子路径运行时文件），并加入 `yaml` 依赖（共享解析器使用）。 |
| `tsconfig.base.json` | 两个子路径别名写在生成区之外的手写块里，`verify-tsconfig-paths` 通过。 |
| 五个 `src/index.ts` | 各自的 Config 声明仍留在包内（`gen-config-catalog` 要求逐包 verbatim 粘贴、拒绝跨包导入），因形状相同用 `/* jscpd:ignore-start */` 包裹并写明原因；共享逻辑不在其中。 |
| `packages/skill/skill-fast-anything/src/index.ts` | 顺手修正从 rust-anything 复制时遗留的插件名 `name = 'skill-rust-anything'` → `'skill-fast-anything'`。 |
| `apps/web/native/dsh-superagent` | 修既有测试腐化：`role-models.spec.ts` 补 SystemPrompt 需要的 `sessionProjections` 桩；`worktrees.spec.ts` 的 `by: 'worker'` 改为 `'executor'` 并补 `TicketMerge.branch`；`runtime.ts` 的 `groupWrites` 改为 `Set<Promise<unknown>>`。剩余 `tests/fixtures/panel-server.ts` 的 TS2719 是既有类型身份问题，未在本轮展开。 |
