## 3. 事故与恢复

改日志后直接 `git commit --amend`，但并行会话期间已在我的提交之上落了 `fix(superagent): clean legacy github-issue thread cursors`：amend 把那份提交并进了我的提交，署名与提交信息都被替换。

恢复：`git reset --soft <对方提交>` 退回原提交 → `git reset` 取消暂存 → 只 `git add` 日志 → 重新提交。恢复前后 HEAD 的 tree 哈希完全相同，对方改动与提交信息零丢失。

规则：`--amend`、`--force` 之前当场核对 `git log -1 --format=%H`，不凭上一步的印象。

## 4. 取舍

- **历史日志只加指针、不改正文**：00097 正文里的 `.agents/skills/rust-anything/` 是当时的事实，日志是历史记录。
- **不在 `SKILL.md` 正文写「用 `/dsh-rust-anything` 调用本技能」**：技能正文面向模型，交代自己的调用方式没有行动价值；面向人的说明放在使用指南里。
- **不扩大 `verify-md-links` 的扫描范围**：把 `native/**` 与根目录报告纳入会把上游 vendored 文档的相对链接一并拉进门禁，属于另一个决策，本轮只记录这个盲区。
