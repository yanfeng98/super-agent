# 00112 — 技能归属到具体插件

- **日期**：2026-11-22
- **背景**：上一轮把菜单标题做成「类别 · 来源」，但运行时注册的技能只能显示成「插件」：注册表把所有 `ctx.skills.register()` 的贡献都记在保留 provider 名 `runtime` 下，不记录是哪个插件注册的；提供方也没有任何方式声明自己是否随 harness 分发。用户要求彻底解决。

## 1. 变更

| 位置 | 内容 |
|---|---|
| `packages/skill/skill/src/index.ts` | 注册时从调用方 fiber 记录插件名（`pluginName(ctx)`，匿名/根 fiber 返回 `undefined`），挂在注册记录与运行时定义上；`SkillSummary` 新增 `owner`、`shipped` |
| 同上 | `SkillProvider` 新增可选 `shipped`：提供方声明自己随 harness 分发。候选对象保持借用，不复制（已有测试断言引用相等） |
| `packages/skill/skill-engineering`、`skill-office` | 声明 `shipped: true` |
| `packages/api/session-controller` | `SkillEntry` 透出 `owner`、`shipped` |
| `packages/client/ui-skill` | 标题规则：`shipped` → `内置 · <upstream>`；插件注册 → `插件 · <owner>`；项目/用户 → `类别 · 目录`；自定义 → `自定义` |
| `apps/web/native/dsh-superagent` | 注册技能时显式带 `owner: 'dsh-superagent'`：它的 scope 是匿名 `ctx.inject` 子上下文，fiber 上没有插件名 |

**显式 `owner` 优先于 fiber**：`register()` 用 `skill.owner ?? pluginName(this.ctx)`。这样匿名 scope（如 superagent 的按会话 skill scope）也能正确归属，而普通插件不用改一行代码就自动带上名字。

## 2. 现在的菜单

```
内置 · mattpocock/skills   eng-*（shipped + upstream）
内置                       office（shipped，无上游）
插件 · dsh-superagent      superagent 注册的技能
项目 · .agents/skills
用户 · ~/.agents/skills
自定义                     dsh-doc（agent-preset 自带）
```

排序：内置 → 插件 → 项目 → 用户 → 自定义 → 其他来源。

## 3. 为什么还是单行

菜单是共享的扁平列表框（`/`、`@`、命令菜单同一个组件），`section` 是一个字符串。真两级（缩进、嵌套标题）要改 `InputTriggerCandidate` 契约和 `MenuView` 渲染，三个菜单一起受影响；而现在 6 个分组用「类别 · 来源」一行已经能表达同样的层级，还省掉 6 行标题的滚动。

## 5. 自查修正

- **`bundled` 源被判成插件**：文件系统提供方配置 `bundledSkillDir` 时，这些技能的 `source` 是 `bundled`，但提供方是 `skill-filesystem`，菜单会显示成「插件 · skill-filesystem」。改为先看 `source === 'bundled'` 判内置，`shipped` 只用于内存注册的贡献。
- **覆盖率跌破 100%**：`pluginName` 的空名分支、`runtimeCandidate`/`toSummary` 的 `shipped` 分支、`skill-catalog` 的 `owner` 未定义分支都没被覆盖。补了匿名 `ctx.inject` 注册、`shipped: true` 的运行时注册、以及一条没有 `owner` 的目录条目；`packages/skill/skill/src/index.ts` 与 `skill-catalog.ts` 回到 100%。
- **子系统文档漏字段**：`SkillListValue` 的枚举句补上贡献插件与 `shipped`。

## 6. 剩余

- 模型侧目录仍只有 `name` + `description`，`owner`/`shipped` 只进输入框菜单，不进模型上下文。
- 真两级标题未做；若以后要做，数据已经齐了（类别 + 来源两个字段都能从 `source`/`owner`/`upstream` 得到）。
