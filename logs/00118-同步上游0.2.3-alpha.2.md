# 00118 — 同步上游 0.2.3-alpha.2

- **日期**：2026-11-22
- **背景**：上游 `deepseek-harness` 在上次同步点（rc.5 回灌的 `master`，2026-11-18）之后前进了 708 个提交（550 个非 merge）、改动 3,225 个文件，依次打出 `dsh-v0.2.3-alpha.1` 与 `dsh-v0.2.3-alpha.2`，`master` 于 2026-11-22 回灌 alpha.2（上游 PR #8961）。用户要求先把本仓库与源仓库同步，再继续改造。
- **判断依据**：两端自上次同步点起都改动过的文件只有 434 个，其余是各自独立的新增；上游这一轮把 Node 底线抬到 `^24.22.3`、把 vendored Cordis 升到 `4.2.0-alpha.1`、把个性化推荐拆成独立包，与本仓库最密集的输入、聊天、设置改动面不重叠，继续叠加改造再同步只会更贵。
- **范围**：整仓；重点在 `packages/client/`、`packages/bundle/`、`packages/connector/`、`packages/session/tool-session-control`、`snapshots/`、`scripts/`、`docs/`、`logs/`。

## 5. 结果

- 本仓库与上游 `0.2.3-alpha.2` 对齐：合并完成时 `git diff upstream/master HEAD` 为 2,298 个文件（+376,556/−3,216 行），差异全部来自本仓库自有能力，主要是两个内置原生包 `apps/web/native/dsh-im` 与 `apps/web/native/dsh-superagent`。
- 保留的能力没有变化：11 个 pi-ai 路由、原生 IM 六渠道、Superagent 工单系统、永久删除会话、编辑重发、按文件夹输入历史、启动片头、Markdown 表格收列、32 个内置工程技能。
- 新增能力随上游进入：`session_send_message` 工具、远程连接页、动作卡片与个性化推荐独立包、五个连接器包、scoped REPL 默认执行模式、Node 24.22.3 底线。

## 6. 遗留

| 项 | 说明 |
|---|---|
| 第三方许可决策 | `@tencent-connect/qqbot-connector` 声明 `UNLICENSED`、`nodemailer` 声明 `MIT-0`，`gen-third-party-notices` 的运行时许可门会拒绝它们。前者需要所有者决定是否随产品分发该 QQ 机器人 SDK；后者是 MIT 的免署名变体，可考虑加入宽松许可白名单。两者都在同步前就存在，本次只补齐了元数据覆盖，没有替所有者做许可决定 |
| 本机沙箱后端 | 本机没有 bubblewrap、Landlock 也不可用，所有 `workspace-write` 的 PTC 场景录制的是 `sandbox-unavailable`（同步前 13 个，同步后 15 个）。这些 fixture 在具备沙箱的机器上会不匹配，与上游录制不同 |
| 其他 hygiene 项 | 见 `pnpm run hygiene` 的实际输出，本次同步未新增失败项 |
