# 00009 — 模型供应商清理汇总

- **日期**：2026-11-13（最后一轮 2026-11-16）
- **背景**：本仓库依次移除了二十个 pi-ai 内置供应商路由（前四条为同一批，`xiaomi-token-plan-ams`、`xiaomi-token-plan-sgp` 随后分别移除，`moonshotai` 与 `moonshotai-cn` 同批移除，`qwen-token-plan`、`qwen-token-plan-cn` 与 `qwen-token-plan-individual` 同批移除，随后移除按量计费的 `xiaomi`，再移除聚合网关 `vercel-ai-gateway`，随后移除推理路由 `huggingface`，随后移除推理云 `cerebras`，随后移除 OpenCode 的按量付费 Console 网关 `opencode`，随后移除 MiniMax 的国际站端点 `minimax`，随后移除 pi 项目的聚合网关 `radius`，随后移除 NVIDIA 自建的推理云 `nvidia`，最后移除第一方路由 `ant-ling`）。每项改动都有独立日志，本文件汇总最终状态、文档与升级路径，便于后续维护与恢复。
- **范围**：`packages/llm/llm-pi-ai`、`docs/user/guide/providers.md`、新增升级指南、Web golden 与 `logs/`。

## 7. 恢复方式

1. 从 `WITHHELD_PROVIDERS` 删除对应 id，并同步调整注释。
2. 更新 `catalog.spec.ts` 的 withheld 列表与 `config.spec.ts` 的参数化列表。
3. 恢复或调整受影响的目录元数据测试（`loader-composition.spec.ts`，若该路由在其中有独立断言）与 3 个 Web golden。
4. 更新包 README、用户指南与升级指南，并重新记录 i18n 哈希。
5. 运行 `vitest packages/llm/llm-pi-ai`、`test:docs`、`build:check` 与 Web e2e 验证。

## 8. 已知限制

- WebKit 浏览器未安装，两个键盘可访问性 e2e 未在 WebKit 下验证；Chromium 已覆盖 golden。
- 运行中的 `127.0.0.1:3080` 进程需要重启才会反映目录变化。
- 不修改 `node_modules/@earendil-works/pi-ai`，避免上游同步冲突与 `verify-provider-data` 漂移。
- `mimo-v2.5-pro-ultraspeed` 随 `xiaomi` 失去全部内置路由；`mimo-v2.6-pro-ultraspeed` 现在只由 `openrouter` 提供（id 为 `xiaomi/mimo-v2.6-pro-ultraspeed`）；如需按量计费直连开放平台，以自定义模型 API 接入 `https://api.xiaomimimo.com/v1`。
- `vercel-ai-gateway` 移除后，其 183 个专有模型 id 失去内置路由；118 个与 `openrouter` 同名的 id 可直接改用 `openrouter`，其余需以 `anthropic-messages` 自定义模型 API 接入 `https://ai-gateway.vercel.sh`。
- `huggingface` 移除后，13 个模型名（DeepSeek-V3 系列三个、MiniMax-M1-80k、Kimi-K2-Instruct 两个、Qwen 五个、MiMo-V2-Flash、GLM-4.6V-Flash）没有其他内置路由；`nvidia` 移除后 `google/gemma-3-4b-it` 也失去唯一的内置路由，因此现为 **14 个**。这些模型需以 `openai-completions` 自定义模型 API 接入 `https://router.huggingface.co/v1`；其余 64 个在 `openrouter` 上有同名条目：29 个换了厂商前缀（不能照抄 Hub 仓库名），35 个前缀相同（4 个 id 完全一致，31 个仅大小写不同）。
- `nvidia` 移除后，11 个模型失去全部内置路由（Nemotron 系列 5 个、Cosmos 1 个、其他厂商开源权重 5 个，见 [00023](00023-移除nvidia供应商.md) 第 3 节）；其余 9 个同名模型仍可在 `baseten`、`groq`、`opencode-go`、`openrouter`、`together` 与 `zai` 上使用；需要原端点时以 `openai-completions` 自定义模型 API 接入 `https://integrate.api.nvidia.com/v1`。
- `ant-ling` 移除后，3 个模型（`Ling-2.6-1T`、`Ling-2.6-flash`、`Ring-2.6-1T`）全部失去内置路由，见 [00024](00024-移除ant-ling供应商.md) 第 3 节；同族的 Ling 3.x Flash 变体仍可在 `openrouter` 上以 `inclusionai/` 前缀使用，但不是这 3 个模型的等价替代；需要原端点时以 `openai-completions` 自定义模型 API 接入 `https://api.ant-ling.com/v1`。
- `opencode` 移除后，84 个模型里 57 个 id、14 个换前缀的同名模型在其他内置路由上仍可取到；其余 13 个中 8 个是只允许 OpenCode 客户端使用的免费档，5 个付费模型（`claude-sonnet-4`、`qwen3.5-plus`、`gemini-3-flash`、`gemini-3.1-pro`、`gpt-5-codex`）需以 `openai-completions` 自定义模型 API 接入 `https://opencode.ai/inference/v1`；同一厂商的订阅路由 `opencode-go` 仍然提供，29 个模型不受影响。
- `radius` 移除后没有模型失去全部内置路由：29 个 id 中 26 个在其他内置路由上原样出现，其余三个是意图别名，`balanced` 等价于 `kimi-k3`（`baseten`、`fireworks`、`github-copilot`、`opencode-go`、`openrouter`、`together`），`cheap` 等价于 `deepseek-v4.1-flash`（`baseten`、`nvidia`、`opencode-go`、`openrouter`、`together`），`precise` 等价于 `gpt-5.6-sol`（`github-copilot`、`openai`、`openai-codex`、`openrouter`）；该路由的 `pi-messages` 协议不在可配置协议表内，需以 `openai-completions` 自定义模型 API 接入 `https://radius.pi.dev/v1`，其 OAuth 登录（pi-gateway 设备码/浏览器回调 `127.0.0.1:1456`）随路由移除，且本构建不再具备其 `/v1/config` 动态目录能力。
