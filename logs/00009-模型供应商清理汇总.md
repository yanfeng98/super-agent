# 00009 — 模型供应商清理汇总

- **日期**：2026-11-13（最后一轮 2026-11-17）
- **背景**：本仓库依次移除了二十五个 pi-ai 内置供应商路由（前四条为同一批，`xiaomi-token-plan-ams`、`xiaomi-token-plan-sgp` 随后分别移除，`moonshotai` 与 `moonshotai-cn` 同批移除，`qwen-token-plan`、`qwen-token-plan-cn` 与 `qwen-token-plan-individual` 同批移除，随后移除按量计费的 `xiaomi`，再移除聚合网关 `vercel-ai-gateway`，随后移除推理路由 `huggingface`，随后移除推理云 `cerebras`，随后移除 OpenCode 的按量付费 Console 网关 `opencode`，随后移除 MiniMax 的国际站端点 `minimax`，随后移除 pi 项目的聚合网关 `radius`，随后移除 NVIDIA 自建的推理云 `nvidia`，最后移除第一方路由 `ant-ling`，再移除 Z.AI 的国际站编码套餐路由 `zai`，最后移除第三方推理云 `baseten`，随后再移除第三方推理云 `fireworks`，随后移除芯片厂商推理云 `groq`，最后移除第一方平台路由 `mistral`）。每项改动都有独立日志，本文件汇总最终状态、文档与升级路径，便于后续维护与恢复。
- **范围**：`packages/llm/llm-pi-ai`、`docs/user/guide/providers.md`、新增升级指南、Web golden 与 `logs/`。

> **后续变更**：原生 IM 集成与四渠道移除分别记录在 [00027](00027-原生集成dsh-im.md)、[00028](00028-移除四渠道.md)；`apps/web/native/` 的文档门禁例外由 00028 引入，上述 `verify-concrete-terms` 失败已消除。

## 3. 控制点

| 位置 | 作用 |
|---|---|
| `packages/llm/llm-pi-ai/src/catalog.ts` 的 `WITHHELD_PROVIDERS` / `isWithheldProvider()` | 在 `servesChat` 前过滤，目录、模型解析、发现、登录、可配置供应商列表随之生效 |
| `packages/llm/llm-pi-ai/src/config.ts` 的 `resolveProfiles()` | strict 与 deferred 下都拒绝点名被移除路由的存量 profile，错误信息指出删除该路由 |

## 7. 恢复方式

1. 从 `WITHHELD_PROVIDERS` 删除对应 id，并同步调整注释。
2. 更新 `catalog.spec.ts` 的 withheld 列表与 `config.spec.ts` 的参数化列表。
3. 恢复或调整受影响的目录元数据测试（`loader-composition.spec.ts`，若该路由在其中有独立断言）与 3 个 Web golden。
4. 更新包 README、用户指南与升级指南，并重新记录 i18n 哈希。
5. 运行 `vitest packages/llm/llm-pi-ai`、`test:docs`、`build:check` 与 Web e2e 验证。
