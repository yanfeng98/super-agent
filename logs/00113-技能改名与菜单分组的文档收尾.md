# 00113 — 技能改名与菜单分组的文档收尾

- **日期**：2026-11-22
- **背景**：技能菜单这一串改动（[00108](00108-技能菜单按来源分组.md) 分组、[00111](00111-内置技能加插件前缀.md) 前缀、[00112](00112-技能归属到插件.md) 归属与「类别 · 来源」标题）落地后，对外可见的行为变了三处，但缺少升级说明与几处包级文档的交代：27 个随包技能换了名字、`/` 菜单换了分组、`skills/list` 多了两个字段。
- **范围**：新增一份升级指南，补齐 `skill-engineering`、`skill-office` 包 README 的 `shipped` 说明，核对已有文档是否与实现一致。不改代码。

## 1. 新增升级指南

`docs/upgrade-guide/v0.2.2-rc.5/engineering-skill-prefix/guide.md`（+ `.zh.md` + pairing 记录）。

外部可感知的破坏性变化是**技能改名**：`/tdd` 不再加载随包技能，`skill({ name: 'tdd' })` 同样失效。指南按仓库模板写「变更 / 迁移」两节：

| 章节 | 内容 |
|---|---|
| 变更 | 27 个名字改为 `eng-*`；为什么加前缀（就近层优先会把随包技能盖掉）；`/` 菜单的新分组；`skills/list` 新增 `owner`、`shipped`；`SkillProvider.shipped` 与运行时注册可声明的 `owner` |
| 迁移 | 逐个替换 `/名字`；同步提示词、`AGENTS.md`、脚本与 `skill({ name })`；重新加载 profile 后确认 `内置 · mattpocock/skills` 出现 |
