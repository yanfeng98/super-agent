## 2. 操作记录

### 2.1 安装 pnpm 11.28.5

- `corepack enable pnpm` 失败：`/usr/bin` 无写权限（EACCES）。
- 改用用户目录：`corepack enable --install-directory ~/.npm-global/bin pnpm`。
- 结果：`pnpm -v` → `11.28.5`，与 `package.json` 的 `packageManager` 一致。
- 影响：仅在 `~/.npm-global/bin` 新增 pnpm 软链，未改动仓库文件。

### 2.2 安装依赖

```sh
pnpm install --reporter=append-only
```

- 结果：成功，耗时 10m17s，退出码 0。
- postinstall 自动配置了 Lefthook 钩子（pre-commit、pre-merge-commit、pre-push）。
- 副作用：生成 `node_modules/`（已被 `.gitignore` 忽略）。
- 注意：安装过程中出现大量 `Tarball download average speed ... below 50 KiB/s` 警告，属于 npmmirror 网络速度提示，不影响安装。

### 2.3 构建产物

```sh
DSH_GATE_CONCURRENCY=1 pnpm run build:artifacts
```

- 选择 `build:artifacts` 而非 `build`：先拿到可运行产物；`build:check`（全仓库测试与脚本类型检查）留到改动代码后再跑。
- `DSH_GATE_CONCURRENCY=1`：本机内存 15G，串行执行避免 Host/Client 两个 8G 上限的 tsc 进程并发导致 OOM。
- 结果：成功，耗时 111.48s，8 个步骤全部 PASS（native addon、Host Typert、host compiler、Host bundle、Desktop bundle、client compiler、Client bundle、Web build），退出码 0。
- 产物：`lib/`、Web 前端 bundle 与 client artifact 记录。日志：`/tmp/opencode/build-artifacts.log`。

### 2.4 中文 README 补全（Discord 入口）

- 检查方式：
  - `pnpm run verify-translation-pairing --list` → 1262 个中英文档对全部 `ok`（0 out-of-sync、0 missing）。
  - 对 475 对 README 做了段落块数量与外部链接集合比对，未发现英文独有内容。
  - 逐段核对了 5 个段落数不一致的 README（ui-plugin-manager、subagent/subagent、ui-settings-plugin-inventory、ui-settings-web-search、ui-open-in-app），中文内容完整。
- 发现的实际差异：根 `README.md` 的社区部分有 Discord 邀请链接，`README.zh.md` 只有企微群，缺 Discord。
- 修改：在 `README.zh.md` 社区列表第 3 项加入 Discord 的 HTML 锚点链接（与英文原文件相同的 `<a href>` 写法，避免破坏配对门禁的链接序列校验），保留企微群二维码表格。
- 记录：`pnpm run verify-translation-pairing --write README.md` 更新 `README.i18n.yaml` 哈希；随后单对校验通过。
- 结论：**英文 README 里有的内容，中文 README 现已全部覆盖**；中文另含企微群二维码，是英文没有的增量。
- 说明：仓库的 `verify-translation-pairing` 门禁要求每个 `foo.md` 必须同时存在 `foo.zh.md` 和 `foo.i18n.yaml`。因此**未删除英文 README**，否则 1262 个文档对会整体报错、且与上游同步时冲突巨大。后续维护以中文为主版本，但每次改中文仍需同步英文对应文件并重新记录哈希（`--write <pair>`）。

### 2.5 启动 Web UI

```sh
pnpm dsh web --no-open
```

- 结果：启动成功，监听 `http://127.0.0.1:3080`。
- 启动日志：`/tmp/opencode/web.log`，PID 记录在 `/tmp/opencode/web.pid`。
- 访问需要 URL 中的 `token` 参数（本机回环地址的访问凭据）；不带 token 请求返回 HTTP 401，属预期行为。
- 模型配置：打开 Web UI 后进入 **Settings → Models**，填入 DeepSeek API Key 即可，无需重启服务。
- 停止服务：`kill $(cat /tmp/opencode/web.pid)`（pnpm 子进程可能需 `pkill -f "dsh web"`）。
- 未创建 `.env`：当前通过 Web UI 保存密钥；如需 headless/SDK 模式运行，再在仓库根目录创建 `.env` 并写入 `DEEPSEEK_API_KEY=...`（该文件已被 `.gitignore` 忽略）。
